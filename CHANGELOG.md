# Changelog

File format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [v0.4] - 2024-06-13

Developed using Godot 4.4.1, ivoyager_core v0.0.25, ivoyager_tables v0.0.4, ivoyager_units v0.0.4.

### Changed
* Updated for plugins split (Tables/Units) and Godot 4.4.1.

## [v0.3] - 2024-09-11

Developed using Godot 4.3, ivoyager_core 0.0.19.dev

### Changed
* Rings exports separate LOD files to support Godot 4.3.
* Asteroids converter reads epoch from source data and tests consistency.


## [v0.2] - 2023-09-25

Developed using Godot 4.1.1, ivoyager 0.0.16-dev.

### Changed
* Asteroid binaries restructured for ivoyager 0.0.16-dev.20230925
* Rings exports 3 textures for ivoyager 0.0.16-dev.20230925


## v0.1 - 2023-03-17

Developed using Godot 3.5.2, ivoyager 0.0.14.

### Added
* Exports binaries for use in ivoyager_assets/asteroid_binaries/.
* Exports Saturn rings texture for use in ivoyager_assets/rings/.
